# Sales Dashboard – Power BI Project

## 📌 Project Overview

This project is an interactive Sales Dashboard developed using Microsoft Power BI. The dashboard provides detailed insights into sales performance, customer behavior, product demand, and revenue trends.

The project transforms raw business data into meaningful visualizations that help businesses make data-driven decisions and improve overall sales strategy.

---

## 🚀 Features

* Interactive sales performance dashboard
* Customer analysis and segmentation
* Product-wise sales tracking
* Revenue and profit insights
* Order trend analysis
* Dynamic filters and slicers
* KPI cards for quick business insights
* User-friendly and responsive dashboard design

---

## 🛠️ Tools & Technologies Used

* **Microsoft Power BI**
* **Power Query** for data transformation
* **DAX (Data Analysis Expressions)** for calculations
* **Excel Files** as data source

---

## 📂 Dataset Information

This project uses three datasets:

### 1. Customers Dataset

Contains customer-related information such as:

* Customer ID
* Customer Name
* Gender
* City
* Country

### 2. Orders Dataset

Contains sales transaction details such as:

* Order ID
* Order Date
* Product Details
* Quantity
* Sales Amount
* Revenue

### 3. Cookie Types Dataset

Contains product category and cookie type information used for analysis.

## 📈 Sample DAX Measures Used

### Total Sales

```DAX
Total Sales = SUM(Orders[Sales])
```

### Total Orders

```DAX
Total Orders = COUNT(Orders[Order ID])
```

### Average Sales

```DAX
Average Sales = AVERAGE(Orders[Sales])
```

### Total Customers

```DAX
Total Customers = DISTINCTCOUNT(Customers[Customer ID])
```

### Revenue Growth

```DAX
Revenue Growth =
DIVIDE(
    [Current Revenue] - [Previous Revenue],
    [Previous Revenue]
)
```
